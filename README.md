# Enterprise AI Knowledge Hub

## Tech stack

- Java 21
- Spring Boot 4.1.0
- Maven (latest compatible with the project)
- Spring AI (latest compatible with Spring Boot 4.1)
- Spring Security (latest)
- MongoDB (latest)
- Redis (latest)
- OpenAI GPT-4.1 / GPT-5 compatible models
- Docker (latest)
- JUnit 5 (latest)

## Project structure

- backend/ - Spring Boot application
- frontend/ - frontend app
- docker/ - container configuration
- deployment/ - deployment assets
- docs/ - documentation
- scripts/ - automation scripts
